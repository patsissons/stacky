---
title: Configuration
description: Environment variables that configure stacky.
---

| Variable                                  | Default                    | Description                                                                                                                                                                                                              |
| ----------------------------------------- | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `STACKY_PORT`                             | `5005`                     | HTTP port to listen on                                                                                                                                                                                                   |
| `STACKY_HOSTNAME`                         | all addresses              | Address to bind to                                                                                                                                                                                                       |
| `STACKY_STACKS_DIR`                       | `/opt/stacks`              | Directory containing one sub-directory per stack. Must be mounted at the same path as on the host                                                                                                                        |
| `STACKY_DATA_DIR`                         | `/app/data`                | Stacky's database and state                                                                                                                                                                                              |
| `STACKY_AUTH_DISABLED`                    | `false`                    | Turn off built-in authentication. Only use this behind a reverse proxy that authenticates for you                                                                                                                        |
| `STACKY_TRUSTED_PROXIES`                  | (none)                     | Comma-separated proxy addresses or CIDRs whose `X-Forwarded-*` headers are trusted                                                                                                                                       |
| `STACKY_ADMIN_USER`                       | (none)                     | Seed the admin username (set together with `STACKY_ADMIN_PASSWORD`)                                                                                                                                                      |
| `STACKY_ADMIN_PASSWORD`                   | (none)                     | Seed the admin password                                                                                                                                                                                                  |
| `STACKY_BASE_URL`                         | (none)                     | Public URL of stacky, used for links (including in notifications) and OIDC callbacks                                                                                                                                     |
| `STACKY_DOCKER_HOST`                      | host of the UI             | Hostname or IP that published container ports are reachable on, used for port links (e.g. `docker.lan` when stacky is served at `stacky.docker.lan`). A bare host, not a Docker socket address                           |
| `STACKY_CONTAINER_ID`                     | autodetected               | Override detection of stacky's own container (used by self-update)                                                                                                                                                       |
| `STACKY_UPDATE_CHECK`                     | `true`                     | Check GitHub for newer stacky releases and show an update banner                                                                                                                                                         |
| `STACKY_UPDATE_SCHEDULE`                  | `6h`                       | Default image update check schedule (`hourly`, `nightly`, `weekly`, `monthly`, `6h`, a cron pattern or `never`); change it in Settings                                                                                   |
| `STACKY_UPDATE_INTERVAL`                  | `6`                        | Legacy: hours between image update checks, used when `STACKY_UPDATE_SCHEDULE` is not set; `0` disables scheduled checks                                                                                                  |
| `STACKY_OIDC_ISSUER`                      | (none)                     | OIDC issuer URL; enables single sign-on (with the client id and secret)                                                                                                                                                  |
| `STACKY_OIDC_CLIENT_ID`                   | (none)                     | OIDC client id                                                                                                                                                                                                           |
| `STACKY_OIDC_CLIENT_SECRET`               | (none)                     | OIDC client secret                                                                                                                                                                                                       |
| `STACKY_OIDC_NAME`                        | `SSO`                      | Label of the sign-in button                                                                                                                                                                                              |
| `STACKY_OIDC_SCOPES`                      | `openid profile email`     | Scopes to request (add `groups` for group checks)                                                                                                                                                                        |
| `STACKY_OIDC_ALLOWED_GROUPS`              | (none)                     | Comma-separated groups allowed to sign in                                                                                                                                                                                |
| `STACKY_OIDC_AUTO_REDIRECT`               | `false`                    | Send visitors straight to the provider (`/login?local=1` shows the form)                                                                                                                                                 |
| `STACKY_REGISTRY_<PROVIDER>_<NAME>_<KEY>` | (none)                     | Registry credentials for update checks, e.g. `STACKY_REGISTRY_LSCR_PRIVATE_USERNAME` / `_TOKEN`; What's Up Docker's `WUD_REGISTRY_*` names work too. See [Private registries](/guides/image-updates/#private-registries) |
| `STACKY_ICON_CDN`                         | selfh.st icons on jsDelivr | Where selfh.st app icons are fetched from (once, then cached); empty disables icon sets (URL labels still work)                                                                                                          |
| `STACKY_LOG_LEVEL`                        | `info`                     | `debug`, `info`, `warn` or `error`                                                                                                                                                                                       |
